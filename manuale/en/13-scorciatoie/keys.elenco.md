# Keyboard shortcuts

Shortcuts work when you are not typing in a text field. The same list opens from
**Help → Keyboard shortcuts**.

## File

| Keys | Command |
|---|---|
| Ctrl+N | New empty scene |
| Ctrl+O | Open project |
| Ctrl+S | Save project |
| Ctrl+Shift+S | Save project as |
| Ctrl+I | Import model |
| Ctrl+E | Export image (PNG, JPG, 16-bit TIFF, EXR) |

## Edit

| Keys | Command |
|---|---|
| Ctrl+Z | Undo |
| Ctrl+Y or Ctrl+Shift+Z | Redo |
| Ctrl+D | Duplicate the selection |
| Delete | Delete the selection (Ctrl+Z brings it back) |
| H | Hide the selection |
| Shift+H | Hide everything else |
| Alt+H | Show all |

## View and tools

| Keys | Command |
|---|---|
| Home | Frame all |
| F | Frame the selection |
| 5 | Perspective / orthographic |
| Q, W, E, R | Select, Move, Rotate, Scale |
| F5 | Start, pause or resume the render |

## Mouse in the viewport

| Action | Effect |
|---|---|
| Drag with the left button | Orbit the camera around the scene |
| Shift + drag, right or middle button | Pan the camera |
| Wheel | Zoom in or out |
| Alt + drag | Move the selection instead of the camera |
| Ctrl while dragging the gizmo | Snap to fixed steps |
| Esc | Cancel the current drag |
