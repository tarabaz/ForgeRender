# Scorciatoie da tastiera

Le scorciatoie funzionano quando non stai scrivendo in un campo di testo. Lo stesso elenco si
apre da **Guida → Scorciatoie da tastiera**.

## File

| Tasti | Comando |
|---|---|
| Ctrl+N | Nuova scena vuota |
| Ctrl+O | Apri progetto |
| Ctrl+S | Salva progetto |
| Ctrl+Maiusc+S | Salva progetto con nome |
| Ctrl+I | Importa modello |
| Ctrl+E | Esporta immagine (PNG, JPG, TIFF 16 bit, EXR) |

## Modifica

| Tasti | Comando |
|---|---|
| Ctrl+Z | Annulla |
| Ctrl+Y oppure Ctrl+Maiusc+Z | Ripeti |
| Ctrl+D | Duplica la selezione |
| Canc | Elimina la selezione (si recupera con Ctrl+Z) |
| H | Nascondi la selezione |
| Maiusc+H | Nascondi tutto il resto |
| Alt+H | Mostra tutto |

## Vista e strumenti

| Tasti | Comando |
|---|---|
| Home | Inquadra tutto |
| F | Inquadra la selezione |
| 5 | Prospettica / ortografica |
| Q, W, E, R | Seleziona, Sposta, Ruota, Scala |
| F5 | Avvia, metti in pausa o riprendi il render |
| F1 | Apre il manuale alla pagina del controllo sotto il mouse |

## Mouse nella viewport

| Azione | Effetto |
|---|---|
| Trascina con il tasto sinistro | Ruota la camera attorno alla scena |
| Maiusc + trascina, tasto destro o centrale | Sposta la camera di lato |
| Rotella | Avvicina o allontana |
| Alt + trascina | Sposta la selezione invece della camera |
| Ctrl mentre trascini il gizmo | Snap a passi fissi |
| Esc | Annulla il trascinamento in corso; altrimenti deseleziona tutto |

## Timeline

| Tasti | Comando |
|---|---|
| Canc | Elimina le chiavi selezionate |
| Ctrl+C, Ctrl+V | Copia le chiavi selezionate e le incolla al cursore del tempo |
| F9 | Rallenta in entrata e in uscita (ease in e out) sulle chiavi selezionate |
